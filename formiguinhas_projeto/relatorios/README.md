# Relatórios

O app `relatorios` reúne consultas e indicadores para apoiar a gestão da ONG.
Ele apresenta dados consolidados de outras áreas, em vez de manter um modelo
próprio.

## Rotas

A página inicial do app está em `/relatorios/`. A view consulta os dados
disponíveis no sistema e os apresenta em templates do próprio app.

Os resultados dependem dos registros existentes nos módulos integrados. Para
detalhes sobre uma área específica, consulte o README daquele app.
