# Opcao mais simples (Windows):
# Na pasta raiz do projeto, execute o arquivo
iniciar.bat
# Ele cria o ambiente virtual, instala todas as dependencias (Django, MongoDB Atlas e bibliotecas),
# verifica a conexao com o Atlas, executa as migrations e inicia o servidor automaticamente.
# Depois acesse: http://127.0.0.1:8000/

# ----------------------------------------

# Opcao manual pelo terminal:
cd formiguinhas_projeto

# 1. Cria o ambiente virtual dentro da pasta do projeto.
python -m venv venv

# 2. Ativa o ambiente virtual.
venv\Scripts\activate

# 3. Instala todas as dependencias (incluindo pymongo, python-dotenv, certifi, dnspython).
pip install -r requirements.txt

# 4. (Opcional) Testa a conexao com o MongoDB Atlas:
python testar_atlas.py

# 5. Cria o banco e as tabelas relacionais do SQLite (as migrations tambem criam os usuarios de teste: ver logins_teste.txt).
python manage.py migrate

# 6. (Opcional) Sincronizacao de dados com o MongoDB Atlas:
python manage.py sincronizar_condominios_mongo
python manage.py sincronizar_acoes_mongo
python manage.py sincronizar_comunicados_mongo
python manage.py sincronizar_auditoria_mongo

# 7. Inicia o servidor do projeto.
python manage.py runserver

# 8. (Opcional) Roda os testes automatizados.
python manage.py test

#    https://myaccount.google.com/apppasswords. Use a senha de app, nao a senha
#    normal da conta. Algumas contas gerenciadas/protecao avancada nao permitem
#    senhas de app.
# 2. Copie formiguinhas_projeto\.env.example para
#    formiguinhas_projeto\.env.
# 3. Edite o .env: use o mesmo endereco Gmail em EMAIL_HOST_USER e
#    DEFAULT_FROM_EMAIL e substitua EMAIL_HOST_PASSWORD pela senha de app
#    (sem espacos).
# 4. Salve o arquivo e inicie normalmente com iniciar.bat. O Django carrega o
#    .env automaticamente, inclusive depois de fechar e reabrir o terminal.
#    O arquivo .env esta ignorado pelo Git; nao o publique nem compartilhe.
# O remetente sera esse Gmail. O link e enviado ao e-mail cadastrado no usuario
# que solicitou a redefinicao. Sem SMTP configurado, o link aparece no terminal.
