=====================================================
  COMO EXECUTAR O PROJETO ONG FORMIGUINHAS
=====================================================

Forma mais simples (Automática):
--------------------------------
1. Abre o terminal na pasta raiz do projeto.
2. Executa o comando:
   .\iniciar.bat

O script vai criar o ambiente virtual (venv), instalar as dependências, 
aplicar as migrações na base de dados e iniciar o servidor sozinho.

3. Acede ao sistema pelo navegador no endereço:
   http://127.0.0.1:8000/


Caso precise rodar manualmente:
-----------------------------------
1. cd formiguinhas_projeto
2. python -m venv venv
3. .\venv\Scripts\activate
4. pip install -r requirements.txt
5. python manage.py migrate
6. python manage.py runserver
